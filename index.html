Kryptonbrowser

Aplikasi browser ujian layar penuh resmi untuk CBT SMP Negeri 3 Jayapura. Ringan, 100% portable dalam satu folder, dilengkapi penguncian shortcut sistem, proteksi screenshot, dan pembaruan otomatis diam-diam dari GitHub Releases.

100% Portable 1 Folder

Semua pengaturan (config.json) dan data WebView2 tersimpan di folder yang sama dengan kryptonbrowser.exe. Cukup atur di satu PC lalu salin foldernya ke seluruh komputer ujian.

Kunci Sistem & Shortcut

Layar penuh terkunci dengan pemblokiran tombol Windows, Alt+Tab, shortcut browser (Ctrl+P, F12, dll.), penyembunyian Taskbar, serta opsi kunci screenshot yang bisa diaktifkan dari Pengaturan.

Auto-Update Silent

Memeriksa dan mengunduh pembaruan dari GitHub Releases secara diam-diam tanpa jendela CMD/PowerShell. Pembaruan hanya diterapkan saat tombol Restart diklik dengan konfirmasi password admin.
